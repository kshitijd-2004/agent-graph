An attacker can supply path traversal sequences (e.g., `../../etc/cron.d/malicious`) to write or delete files outside the intended vault directory.\n\n**Evidence:**\n```python\n# src/main.py, store() line 18\nfilepath = os.path.join(VAULT_DIR, filename)\nwith open(filepath, \"w\") as f:\n    f.write(content)\n\n# src/main.py, delete_file() line 44\nfilepath = os.path.join(VAULT_DIR, filename)\nif os.path.exists(filepath):\n    os.remove(filepath)\n```\n\nNo call to `sanitize_filename()` or any path validation is made before using the filename.\n\n**Impact:** Arbitrary file write and deletion anywhere on the filesystem accessible to the process.

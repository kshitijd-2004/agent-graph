## NOT YET VALIDATED (requires Phase B — two human annotators)

Nothing below can be claimed without genuine human labels:

1. **Extractor accuracy** (precision/recall/F1 vs adjudicated labels), per
   dimension and family — `scripts/evaluate.py --stage full` is implemented
   and hard-stops on `HumanLabelsMissing` until
   `annotation_templates/ADJUDICATED.jsonl` exists.
2. **Divergence classification validity** — human judgments of whether a
   meaningful behavioural difference exists, vs the four BND indicators, the
   union, and the frozen vs v6 implementations.
3. **Zero-threshold sensitivity** — the human-confirmed divergence rate for
   the 3,777 zero-threshold-dependent union positives; the calibration/
   evaluation split for any alternative thresholds.
4. **M1–M4 propagation evidence** — the small evidence-rich set mapping
   delivery → local divergence → downstream divergence → final degradation
   (M4-matched vs historical M4).
5. **Inter-annotator reliability** — κ/α on categorical, binary and
   numeric labels; adjudication log.

**A passing test suite does not establish BND measurement validity.** This
framework proves the machinery is correct, reproducible, and contained;
whether the four dimensions capture behavioural difference is settled only in
Phase C against Phase B labels.
